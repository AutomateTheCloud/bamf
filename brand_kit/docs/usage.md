# BAMF logo usage

## Clear space and minimum sizes

For the BAMF lockup, leave at least 10% of the overall artwork width clear on each side. More is welcome. The embedded ATC badge must retain its proportions, pixel steps and dither grid, with breathing room around it.

Suggested digital minimums for this detailed artwork:

| Asset | Minimum width |
|---|---|
| Full stacked lockup with subtitle | 480px |
| Compact mascot + BAMF | 240px |
| Horizontal with subtitle | 700px |
| Standalone mascot | 96px |
| Wordmark only | 96px |
| B favicon | 16px |

These are practical BAMF recommendations, not replacements for the Automate the Cloud (ATC) parent-mark rules. At smaller sizes switch variants rather than scaling an unreadable subtitle. At tiny sizes use the B favicon; do not try to preserve all the mascot or cloud detail.

## Keep consistent

Keep the character, badge position and size, lettering, and palette together. Scale uniformly. Do not skew, stretch, rotate, add shadows, gradients, glow or texture. Use the supplied one-color versions for one-ink work. Keep the ATC mark's filled outline and original path geometry; do not replace it with a stroke.

The dark asset uses a narrow filled keyline around the outer mascot for visibility; it does not add a stroke to the ATC cloud mark. Do not apply the dark asset on a pale surface.

## Typography

IBM Plex Mono: headings, code, figures and labels. Space Grotesk: body text. IBM Plex Serif: occasional pull quotes and epigraphs. The BAMF wordmark remains its bespoke outlined artwork.

## Naming

Use BAMF in uppercase. Spell out BASH Application Management Framework when introducing the project. Use American English in copy, comments and file names.
